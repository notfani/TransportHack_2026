# Допущения, ограничения, параметры

## Допущения

1. Тележка в bag — км/ч (`wheel_input_unit: kmh`). Выход `/result/velocity` — м/с.
2. Ручка: 0 нейтраль, плюс тяга, минус тормоз, целые \([-15,15]\).
3. Трамвай не едет назад: \(v\ge 0\).
4. GNSS — только старт (master fix, окно 3 с). Скорость GNSS в рабочем контуре не используется.
5. Карта — локальный pathgraph (метры, касательная, кривизна). Совпадение с кадром автоматической проверки жюри не подтверждено; задаётся `output_*` в params.
6. Масса, сцепление, уклон, загрузка не измеряются разрешёнными топиками. Масса 24 т и \(\mu=0.2\) — априори; адаптация только \(k\) на доверенных колёсах.
7. При полной потере входов оценка продолжается моделью ограниченное время, неопределённость растёт.

## Конфигурируемые параметры

Файл `src/tram_odometry/config/params.yaml` (и `hybrid.json` / таблица привода).

| параметр | смысл | типичное |
|---|---|---|
| `wheel_input_unit` | единицы тележки | `kmh` |
| `drive_model_kind` | `hybrid` / `table` | `hybrid` |
| `start_mode` | выставка | `gnss` |
| `initialization_window_s` | окно GNSS после первого fix | 3.0 |
| `start_x_m, start_y_m, start_yaw_rad` | ручной старт без GNSS | 0 |
| `output_x/y/z/yaw` | жёсткий сдвиг в кадр жюри | 0 |
| `watchdog_period_s` | такт при паузе | 0.02 |
| `command_timeout_s` | устаревание ручки | 0.2 |
| масса, \(a_t,a_b,F_{\max},\mu,c_r,c_a\) | физика | см. MODEL.md |
| пороги юза, \(\sigma\) колёс, \(\tau\) фильтра | оценщик | `estimator.*` |

Смена без правки исходников:

```bash
bash scripts/run.sh bag:=/путь/к/bag \
  params_file:=src/tram_odometry/config/params.yaml \
  -p drive_model_kind:=table
```
