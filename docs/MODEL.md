# Математическая модель

Вход основного контура: положение ручки \(u\in[-15,15]\) и скорости тележек. GNSS после окна выставки (~3 с) в контур скорости не входит.

Скорости тележек в записи — км/ч; в СИ один раз: \(v_w = v_{\mathrm{km/h}}/3.6\).

## Продольная динамика

Номинальное ускорение по ручке и текущей оценке скорости \(v\) (не сырым колёсам):

- тяга \(u>0\): \(a_{\mathrm{nom}}=\min\bigl(a_t\,(\min(u/u_t,1))^{p_t},\; (P/m)/\max(v,0.5)\bigr)\)
- тормоз \(u<0\): \(a_{\mathrm{nom}}=-a_b\,(|u|/15)^{p_b}\)
- нейтраль: \(a_{\mathrm{nom}}=0\)

Дефолты: \(m=24\,\mathrm{т}\), \(a_t=1.2\,\mathrm{м/с^2}\), \(u_t=10\), \(a_b=1.3\,\mathrm{м/с^2}\), \(p_b=0.7\), удельная мощность \(P/m=12\,\mathrm{м^2/с^3}\).

Сила и сопротивление:

\[
F=\mathrm{clip}(m\,a_{\mathrm{nom}}\,k,\;\pm\min(F_{\max},\;\mu mg)),\quad
a_{\mathrm{res}}=c_r+c_v v+c_a v|v|
\]

\[
a_{\mathrm{model}}=\mathrm{clip}\bigl(F/m-a_{\mathrm{res}},\;[-a_{\max},\,a_{\max}]\bigr)
\]

\(F_{\max}=48\,\mathrm{кН}\), \(\mu=0.2\) (верхняя оценка сцепления, не измерение), \(c_r=0.025\,\mathrm{м/с^2}\), \(c_a=2\cdot10^{-4}\,\mathrm{м^{-1}}\). \(k\) — ограниченный коэффициент тяги/торможения \([0.65,1.35]\); обновляется только на доверенных колёсах без юза.

Гибридный режим (по умолчанию): к \(a_{\mathrm{model}}\) добавляется обученная невязка по признакам \((u,v,\mathrm{EMA}_u, a_{\mathrm{колёс}}^{\mathrm{trust}}, \mathrm{возраст})\). Вне 0.5–15 м/с, при юзе, дыре входа или устаревшей памяти остаётся чистая физика. Веса экспортированы в обычный Python, CatBoost в рантайме нет.

Табличная карта \(u,v\to a\) доступна параметром `drive_model_kind:=table`.

## Оценка скорости и положения

Состояние \([s,\,v,\,b_a]\), причинный фильтр. Гипотеза колёс — согласованное среднее; при разгоне и разъезде тележек доверие падает.

Признаки недоверия (юз/аномалия): разъезд перед/зад; скачок \(\omega r\) без \(a_{\mathrm{model}}\); большая |тяга| при малом \(|\dot v_w|\); при торможении колёса падают быстрее модели.

- высокое доверие — коррекция по колёсам;
- низкое — интегрирование \(a_{\mathrm{model}}\);
- \(v\ge 0\), ограничение ускорения, удержание последнего \(v\) на коротком обрыве входа.

Путь: \(s\leftarrow s+v\,\Delta t\). При выставке GNSS master (окно 3 с) проекция на pathgraph, публикация в `pathgraph`; иначе `odom_relative` от старта. После закрытия окна GNSS скорость не корректирует.

Такт: ~20 Гц по ручке; watchdog 20 мс при паузе входа. Будущие измерения не используются.
